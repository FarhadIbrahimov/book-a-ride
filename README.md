# Happy Skewer

Marketing website for Happy Skewer — authentic Azerbaijani catering (charcoal-grilled kabobs and
traditional pilav) for weddings, corporate events and private celebrations.

Built with React, Vite, Tailwind CSS and React Router.

## Development

```bash
npm install
npm run dev
```

## Editing business details

Phone, email, address and social links live in `src/siteConfig.js`. Menu items and dish photos
live in `src/data/menu.js` and `src/assets/menu`.
